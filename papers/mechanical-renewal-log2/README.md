# Mechanical renewal and D²(ln D)² lower bounds for Hilbert numbers

Frozen version: 2026-10-24. [Public record](https://doi.org/10.5281/zenodo.23603842).

Finite exact integer and degree-budget checks; these do not certify the analytic realization theorem.
